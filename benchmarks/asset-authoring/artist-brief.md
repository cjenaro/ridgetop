# Lantern Grove art assignment

Create all 20 assets in `briefs.json`. The client is making a coastal woodland exploration game in Ridgetop. Each asset must work as a selectable 3D model and as a 32-pixel directional sprite. Build the named object and the requested distinguishing features. Use strong silhouettes, readable proportions, and the starter's muted woodland colors. The game looks down at 30 degrees. Each object must also make sense from the side and rear.

Submit one version-1 Ridgetop recipe per brief as `<id>.art.json`, with the same ID in the recipe's `name`. Use `frameSize: 32`, `palette: {}`, the eight stock palette roles, and at most 32 individually named parts. Use the five supported shapes. Keep the object's base at Y=0 with X,Z centered around its footprint, and choose a camera span and vertical center that frame the whole object with a small margin. Front is +Z. Physical dimensions can differ by object. Name each significant part so a reviewer can request a local edit. Features need to read from at least one natural viewing angle. You may choose an orientation that suits the brief.

The approved references are the stock recipes in `framework/art.ts` and `starter/art/rain-ranger.art.json`. The schema and palette are in `framework/art-recipe.ts` and the shape coordinates in `framework/geometry.ts`. Boxes and chamfered prisms have unit width, height and depth. The seven-sided cylinder and cone have unit radius and unit height. The octahedron has unit radius on all three axes. Part yaw rotates about Y. Use the engine's geometry and palette as supplied. No downloaded assets or images, external services, new packages, or extra agents.

You may write a local helper to generate JSON and use the existing Node validator to correct formatting or schema errors. This first submission tests authoring from text and the same code examples. Stop before visual rendering or visual revision. Keep helpers outside the submission directory. Treat the other participants' work as private. Return only completion or a concrete blocker to the coordinator.
