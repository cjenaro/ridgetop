# Ridgetop Bug & Performance Patterns

Distilled, repeatable failure modes and verification traps learned from prior bug hunts.
Keep entries concise and pattern-oriented (merge/prune on each run; do not turn this into a chronological changelog).

## 1. Game Framework

- **Backend parity & resource leaks**: WebGPU (`mesh-gpu.ts`), WebGL 2 (`mesh-gl.ts`), and Canvas 2D (`mesh-canvas.ts`) must agree on winding, depth, transforms, colors, alpha sorting, shadows, and lights. Check `releaseMesh()` destroys *both* vertex buffers and associated instance buffers, enforce `device.limits.maxBufferSize`, guard `createRenderer` `end()`/`dispose()` plus opaque Canvas 2D clear, snapshot `prevNear` before overwriting in `packLighting()`, update the active `light` reference in `canvasMeshes.setLighting(next)`, clamp `createAlphaSorter(0)`/`createParticles(0)`, and call `cleanup()` if `source.start()` throws in `createAudioBank.play()`.
- **Hot-loop allocations**: Avoid per-vertex / per-instance temporary arrays, `subarray()` allocations, rest spreads (`Math.hypot(...q)`), repeated CSS `rgba(...)` string formatting, idle `getGamepads()` array allocations, `structuredClone()` of already-cloned payloads, or per-collider / per-joint / per-particle scratch objects in `slideSphere`, `projectShadow`, `renderRig`, `createParticles.emit`, and `mesh-canvas.ts` (pool `Face` objects on moving-camera frames).
- **IEEE-754 boundary epsilons**: Fixed-step platformer landing/pad overlap checks need a tiny epsilon (`1e-9`) so `y + vy * dt` ULP drift does not bounce players off flat surfaces on the next tick.
- **Re-entrant lifecycle & state machines**: Update state (`current = next`) *before* invoking transition `action()` callbacks and guard `exit()` with an active-exiting `Set`; update gamepad edge flags before firing callbacks; guard `fixedLoop`, `bindMenuGamepad`, and Canvas UI rAF timers against `stop()`/`dispose()` mid-callback; restart `bindActionControls` gamepad polling when Testing Mode resumes; dispose any prior `mountTestingStudio()` instance before re-mounting and guard async initial review fetches against disposal.
- **Canvas UI & Input edge cases**:
  - `navigator.getGamepads()` returns a `GamepadList` (not a plain `Array`—never assume `.filter` exists directly).
  - Always guard `setPointerCapture` in `try/catch`; scope `interactiveHits()` above the topmost visible modal scrim so keyboard/gamepad/programmatic focus cannot pierce modals; track slider drags per-pointer; release multi-touch `onHold` only when the last pointer on that button lifts; check `disabled` *before* dispatching primitive `act()`; skip disabled `<option>`s in `bindMenuGamepad`; reset `canvas.style.cursor` on `dispose()` and guard `iconSize > 0`.
- **Server, networking & multi-runtime**:
  - Never assume Node-only globals (`Buffer`, unimported `process`) in runtime-agnostic or strict-ESM modules—use `TextEncoder` and explicit `node:buffer` / `node:process` imports; guard error `.code` with narrowing.
  - Check raw UTF-8 byte length (`Buffer[]`), run room tick intervals lazily while `rooms.size > 0`, delay inserting empty rooms until a member is created, and check `res.destroyed || res.writableEnded` on SSE `join()` and broadcast.
  - WebSocket (`room-server.ts` / `room-client.ts`): attach `socket.on('error', ...)` *before* writing `101`/welcome or rejecting upgrades; validate RFC 6455 wire close codes (`1000..1003`, `1007..1011`, `3000..4999`), UTF-8 close reasons (`1007`), and 64-bit length MSB (`1002`), truncate outgoing close reasons on UTF-8 boundaries, and set a destroy timeout on `closeSocket()`. Pace flush-driven auto-prediction to fixed 60Hz `STEP`, put `type: 'input'` *after* payload spread, rebase `jumpOffset` on new player ID, initialize `sentAt = -Infinity`, guard SSE callbacks against `closed`, and emit `Content-Length` on `HEAD`.

## 2. Asset Building

- **Binary, mesh & rasterization hot paths**: Use `zlib.crc32` (with table fallback) and single-alloc chunk assembly in `png.ts`; never spread into `Math.min`/`Math.max`/`Math.hypot` (`ridgetop/no-math-spread`); use packed `Uint32Array` fills and precomputed edge scanlines in `sprite-sheet.ts`; build flat triangle buffers directly in `import-mesh.ts` and inline face normals in `geometry.mesh()` without per-triangle array churn.
- **GLB/OBJ & rigged art validation**: In `import-mesh.ts`, enforce single-parent tree rules (rejecting $O(2^N)$ DAG blowups) and detect pure cycles when `scenes` is omitted; validate plain-object JSON, safe-integer `bufferView` bounds, Float32 transform overflow, and integer array indices (blocking prototype lookups like `"slice"`); strip OBJ `#` comments *before* backslash line continuation. Guard `rigFromArtModel` against `Object.prototype` joint names and `root`+`__static__` collisions, guard `compileArtJoints` against cycles, shift omitted-pivot root joints in `fitArtRecipe`, validate `center.length === 3` in `bakeSpritePixels`, and treat `'rig'`/`'mesh'` as 3D surfaces in `modelReviewFrame`.
- **Recipe, builder & review store validation**: Reject JSON `null`/sparse arrays in numeric fields using indexed `for` loops + `Number.isFinite`; handle malformed JSON/corrupted store files with HTTP 400 (never 500); compare `Content-Type` case-insensitively; enforce loopback on `req.socket.remoteAddress` alongside `Host`/`Origin`; block prototype asset keys and `/__testing/sprite` overwrites of `overrides.json`/`*.art.json`; defer `mkdir(reviews)` until after route matching; never block read-only GETs behind the write mutex.
- **Headless picking, part names & offline HTML**: Keep `pickArtScene` headless; disambiguate duplicate part names in `spritePartVisibility` using `Object.defineProperty`; mark `sprite-workshop` templates dirty on swatch edits; escape `</style` in inline offline bundles (`standalone-page.ts`).

## 3. Example Games

- **Per-frame UI churn & re-entrant primitive sync**: Compare state keys before re-syncing UI primitives, guard programmatic updates with `syncing*` flags, avoid 30Hz HUD redraws on paused/modal screens, and expose synchronous `renderUiNow()` around `__ridgetopUi.act()`.
- **Simulation events, input & scene lifecycle**:
  - Drain per-tick VFX/SFX queues on consumption, run audio updates across non-playing screens so modal/victory SFX aren't dropped, and pass real clamped `renderDt` (`0` when paused) rather than hardcoded `1/60`.
  - Check `event.defaultPrevented` on secondary `window` `keydown` listeners so a key handled by `bindActionControls` doesn't double-toggle in the same event; never bind `Tab` away from modal focus navigation; reserve carry slots for in-flight pulled items; use `renderer.canvas.focus()` (not stale pre-fallback `stage`).
  - Racing: checkpoint shoulder margin (`width * 0.85`), exact `toGate === 0` wrap, non-negative modulo in `standings()`, freeze `driver.progress` while wide, guard weapon queueing during countdown, and only `releaseMesh()` scene-owned procedural meshes in `dispose()`.
- **Hosted vs standalone & Testing Mode seams**: Pass `testingOptions: { artDir }` from multi-game root servers (e.g. `examples/starter/art`), pass `hosted: false` on standalone example servers to strip `data-hosted="1"`, keep `examples/starter/` and `packages/ridgetop/templates/starter/` in parity, and resolve dist-relative asset paths via `import.meta.url.endsWith('.ts')`.

## 4. Compiler to Godot & Packager

- **TS → GDScript 4 compiler (`packages/ridgetop/tools/ts-to-gd.ts`)**:
  - Short-circuit `&&`/`||`/`??`, logical assignments, and optional calls (`fn?.(sideEffect())`, `obj?.method(arg)`) via guarded hoist frames; evaluate receivers and LHS targets *before* arguments/RHS; `prop_len(null)`/`prop_size(null)` return `null`.
  - Handle `arr.length = n` resizing in `RT.set_prop`, dynamic `Map`/`Set` method dispatch in `RT.get_prop` (avoiding Godot 4 Dictionary↔Callable refcount cycles), `Reflect.apply`/`get`/`set`, numeric dict key normalization (`RT.norm_key`/`RT.has_prop`) across `in`/`Object.hasOwn`/computed keys, `RT.invoke` for spread top-level calls, multi-line lambda indentation in `else if`, nested `switch` `continue` propagation, `do..while` continue, exact `int64` `is_safe_int` (never `absf()`), `rootDir` containment in `computeRelOutputPath()`, and bare `ridgetop/*` entries in CLI.
  - Lazily `await import('./ts-to-gd.ts')` in `cli.ts` so non-Godot CLI commands work when optional `typescript` peer is absent.
- **Godot exporter & runtime (`packages/ridgetop/framework/export-godot.ts`)**:
  - Compute glTF `accessor.min`/`max` from `Float32Array` values, assemble GLB in one `Buffer.concat`, and attenuate `baseColorFactor` by `(1 - unlit)`.
  - In `ridgetop_runtime.gd` and generated scripts: use `Basis(q).scaled_local(safe_scl)` (not `.scaled()`, which shears rotated non-uniform meshes), support scalar joint `scale` in `RigInstance.apply_poses()`, `queue_free()` ambient bed players in `cleanup()`, use live `__rt_getter` for `createRng.seed`, check `dict.has(k)` before `dict[k]`, escape `\r`/`\n`/`\t` in `godotEscape`, and guard `_draw_faceted`.
- **Packager & scaffold (`packages/ridgetop/framework/packager.ts`, `tools/create-game.ts`)**:
  - ES module scanner must handle comments/strings/templates/RegExp AND two-char `++`/`--` tokens so `i++ / n` doesn't misclassify `/` as a RegExp.
  - Enforce containment (`resolveContained`) *before* reading/writing `<link>` hrefs, `staticFiles`, `staticDirs`, `overridesReset`, and player `readAsset`/`readModule`; support namespace/re-export `ridgetop/testing` stripping and namespace `ridgetop` PRNG barrel pruning; wrap `new URL('./', location.href)` in `try/catch` for `about:srcdoc`/`data:` URLs; preserve `assets.title` when `config.name` is unset; keep Capacitor/Electron security guards intact.

## Verification Environment Gotchas

- **Correctness linter (`npm run lint`)**: Uses `oxlint` (`.oxlintrc.json` + `tools/oxlint-ridgetop-plugin.mjs`) over all production code (`test/` exempt) forbidding non-const type assertions (`consistent-type-assertions: never`), `!`, `any`, `@ts-ignore`/`@ts-expect-error`, empty `catch {}`, `eqeqeq`, `eval`/`new Function`, and `Math.min/max/hypot(...spread)`. Run `npm run lint` after every edit batch.
- **Godot 4 silent script errors**: `godot --headless --path <dir> --quit-after 5` often exits with **code `0`** even when GDScript parse or runtime errors occur! Always assert `stderr.trim() === ''` across **all 4 games** (`signal-drift`, `beacon-run`, `starter`, `lighthouse`) via `scripts/godot-smoke.mjs`.
- **Headless Chrome WebGPU on Linux**: Plain `--enable-features=Vulkan` causes `SharedImageStub: Unable to create shared image` and WebGPU device loss fallback to WebGL 2. Always launch headless Chrome with:
  `--enable-unsafe-webgpu --enable-unsafe-swiftshader --use-gl=angle --use-angle=vulkan --use-vulkan=swiftshader --enable-features=Vulkan`.
- **Node 24 native TypeScript**: Run `.ts` files directly with `node` (never `npx tsx`, which prompts to install packages).
